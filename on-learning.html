First day learning HTML and CSS using Codex

Codex is actually a very good teacher. The only thing I'm worried about is industry conventions. I don't want to be writing disgusting code.

Also, I wouldn't recommend writing HTML in Neovim without configuring it first. My current setup has no code completion, so every tag needs to be written by hand.

I'm sure there's a plugin somewhere that solves this problem. Maybe I'll track one down when I write more HTML. But since this blog is the only place where I write HTML, it doesn't seem worth the hassle yet.
